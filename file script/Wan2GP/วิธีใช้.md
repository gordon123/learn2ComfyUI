🚀 Wan2GP Installation Guide for RunPod <br>
Complete installation guide for Wan2GP with SageAttention 2 on RunPod. <br>
📋 System Requirements <br>

GPU: RTX 4080+ (16GB+ VRAM recommended) <br>
RAM: 32GB+ recommended <br>
Storage: 100GB+ for models and dependencies <br>
RunPod Image: runpod/pytorch:2.4.0-py3.11-cuda12.4.1-devel-ubuntu22.04 <br>


1. download file install wan2GP
2. 🎯 Usage การติดตั้งครั้งแรก:

```
cd /workspace
chmod +x install_wan2gp.sh
./install_wan2gp.sh
```
แล้ว
```
cd /workspace
./install_wan2gp.sh
```

3. check ลงครบไหม ผ่านไหม
ดาวโหลดไฟล์ check_status

4. quick run เอาไว้ run program แบบไม่เช็คอะไร

5. run_wan2gp จะ เช็คสถานะ และเปิดโปรแกรม

ทุกไฟล์ต้อง chmod +x เสมอ ดังในตัวอย่าง ทำครั้งแรก
หลังจากนั้น run ./install_wan2gp.sh ได้เลย
