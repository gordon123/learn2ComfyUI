# Learned Additions — ความรู้ที่เพิ่มเข้ามาระหว่างใช้งาน

ไฟล์นี้เริ่มต้นว่างเปล่า จะถูกเติมเนื้อหาโดย Claude เองตามกลไก **เฟส 5 (self-updating loop)** ใน `SKILL.md` — ทุกครั้งที่เจอคำถามที่ reference หลัก 3 ไฟล์ (`songwriting-craft.md`, `prosody-and-tone.md`, `suno-prompting.md`) ตอบไม่ได้ และ Claude ต้อง web search มาเพิ่ม แล้ว user คอนเฟิร์มแล้วว่าใช้ได้ ให้เพิ่มรายการใหม่ต่อท้ายไฟล์นี้ตามฟอร์แมต:

```
## [หัวข้อสั้น ๆ] — เพิ่มเมื่อ [วันที่]
สรุปสิ่งที่พบ: ...
แหล่งที่มา: [URL หรือชื่อแหล่ง]
บริบทที่เจอ: [เจอตอนแต่งเรื่องอะไร / genre ไหน]
```

**เมื่อเริ่มงานใหม่ทุกครั้ง ให้ scan ไฟล์นี้ก่อนว่ามีความรู้ที่เกี่ยวข้องกับงานปัจจุบันอยู่แล้วหรือไม่** จะได้ไม่ต้องค้นซ้ำสิ่งที่เคยหาไว้แล้ว

หากไฟล์นี้ยาวเกิน ~150 บรรทัด และเริ่มมีหลายรายการเกี่ยวกับหัวข้อเดียวกัน ให้เสนอ user ว่าจะย้าย/รวมเนื้อหาที่เกี่ยวข้องเข้ากับ reference หลักไฟล์ที่ตรงหัวข้อ เพื่อให้ reference หลักทันสมัยอยู่เสมอ แล้วค่อยล้างรายการที่ย้ายไปแล้วออกจากไฟล์นี้
