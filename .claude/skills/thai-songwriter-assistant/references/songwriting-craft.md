# Songwriting Craft — เทคนิคแต่งเนื้อหาเพลงไทย

อ้างอิงจากซีรีส์ "มาแต่งเพลงกันเถอะ" (Puntaiji Entertainment, อิงคอร์ส Songwriting ของ Coursera) และคลังเทคนิค 16 ข้อ

## 16 เทคนิคขั้นเทพ (ใช้ตอน user ติดไอเดีย นึกไม่ออกว่าจะเขียนท่อนไหนต่อ)

1. **เขียนให้มีสัมผัส** — ช่วยให้จำง่าย ฟังลื่นไหล (รายละเอียดสัมผัส 6 ประเภทดู `prosody-and-tone.md`)
2. **ย้ายจุดสัมผัส** — ไม่ต้องสัมผัสท้ายวรรคเสมอไป ลองย้ายตำแหน่งเพื่อความเป็นธรรมชาติของประโยค
3. **เลือกใช้สระง่าย ๆ** — เพิ่มตัวเลือกคำสัมผัสให้มากขึ้น
4. **อย่าใช้คำซ้ำเยอะ** — ฟังแล้วน่าเบื่อ จำเจ **(กฎเช็กจริง: หลังร่างแต่ละบท/ท่อนเสร็จ ให้ไล่คำทุกคำในทุกวรรคของบทนั้นทีละคำ ถ้าคำเนื้อหา (ไม่ใช่คำเชื่อมทั่วไปอย่าง ก็/ที่/จะ) ซ้ำกันเกิน 1 ครั้งในบทเดียวกัน ให้หาคำพ้องความหมายมาแทนคำที่ซ้ำ — ยกเว้นตั้งใจซ้ำเพื่อเป็นเทคนิคทำฮุค/คำเน้นย้ำใน Chorus ซึ่งเป็นการตัดสินใจเชิงศิลป์ ไม่ใช่ความผิดพลาด)**
5. **เขียนให้ถูกโน้ต** — ถ้าไม่จำเป็นจริง ๆ อย่าไปแก้ทำนองเพื่อให้เนื้อร้องลงตัว ให้แก้เนื้อร้องแทน
6. **คิดคำจากเมโลดี้เด่น ๆ** — ถ้ามีทำนองอยู่แล้ว ฟังว่าตรงไหนสะดุดหู เอาตรงนั้นมาขยายเป็นไอเดีย
7. **คิดท่อนฮุคก่อน** — ฮุคคือสิ่งที่คนจำขึ้นใจที่สุด ลองคิดคำ/วลีฮุคก่อนค่อยแต่งท่อนอื่นล้อมรอบ
8. **ล้อคำ ล้อโน้ต** — ทำให้เพลงสละสลวย จำง่ายขึ้น
9. **เล่นคำ** — เล่นเสียงพยัญชนะ/คำที่คล้ายกัน (wordplay)
10. **ใช้คำขัดแย้งเล่าเรื่อง** — สร้างมิติ ความน่าสนใจให้เนื้อหา
11. **ใช้สำนวน/การเปรียบเทียบ** — หลุดจากเพลงเดิม ๆ เพิ่มเสน่ห์
12. **หาประโยคมีน้ำหนักมาใส่** — ประโยคเด็ด ๆ ทำให้เพลงกินใจ มักใส่ในจุดพีคหรือท่อนจบ
13. **เขียนเป็นธีม (Theme)** — ไม่ต้องมีเรื่องราวซับซ้อนก็ได้ แค่ถ่ายทอดอารมณ์เดียวให้ชัด
14. **เขียนเป็นพล็อต (Plot)** — วางลำดับเหตุการณ์ทั้งหมดก่อน แล้วค่อยหยิบมาแปลงเป็นเนื้อเพลง
15. **อ่านอารมณ์ของเมโลดี้ให้ออก** — ก่อนเขียนต้องรู้ว่าเพลงนี้ "ทางไหน" (สนุก/เศร้า/ปลุกใจ ฯลฯ)
16. **วางแผนการเล่าเรื่อง** — หัวใจสำคัญสุด ต้องสื่อสารให้คนหมู่มากเข้าใจได้ (เว้นแต่ตั้งใจทำเพื่อกลุ่มเฉพาะ)

## เครื่องมือปั้นเนื้อหา (ใช้ในเฟส 1 ของ workflow)

### 5W1H — "เพื่อนสนิททั้ง 6"
คำถามช่วยจับประเด็นเนื้อเรื่อง ไม่ต้องตอบครบทุกข้อ แต่อย่างน้อยควรมี **ใคร** + **ทำอะไร/รู้สึกอะไร** เป็นแกน:

- **Who** ใคร
- **What** ทำอะไร มีอะไร
- **Why** ทำไม
- **When** เมื่อไหร่
- **Where** ที่ไหน
- **How** อย่างไร

ตัวอย่างการแปลงคำตอบเป็นเนื้อเพลง (จากต้นฉบับ):
> ใคร=ฉัน / ทำอะไร=แอบรักเธอ / ทำไม=ทำไมก็ไม่รู้ / เมื่อไหร่=วันแรกที่พบเธอ / ที่ไหน=ค่ายรับน้อง / อย่างไร=พยายามเข้าใกล้เธอ
>
> → "ในวันแรกของค่าย ใจฉันก็ละลาย เพราะแอบรักเธอ / ตั้งแต่ที่ได้พบเธอ มันคอยละเมอ เป็นเพราะเหตุใด / ก็เลยต้องคอย ๆ ไปอยู่ใกล้ ๆ เธอ..."

### Point of View (มุมมองบุคคล)
เลือกว่าจะเล่าเป็น **"ฉัน"** (บุคคลที่ 1) **"เธอ"** (บุคคลที่ 2 — พูดกับใครคนหนึ่งตรง ๆ) หรือ **"เขา"** (บุคคลที่ 3 — เล่าเรื่องคนอื่น) มุมมองนี้ต้องคงเส้นคงวาตลอดทั้งเพลง (ยกเว้นตั้งใจสลับเพื่อเอฟเฟกต์พิเศษ เช่น ท่อนหนึ่งเป็น "ฉัน" อีกท่อนเป็น "เธอ" ในเพลง duet)

### Theme vs Plot
- **Theme** — ถ่ายทอดอารมณ์/แนวคิดเดียว ไม่มีลำดับเหตุการณ์ชัด เหมาะกับเพลงที่เน้นความรู้สึกล้วน ๆ
- **Plot** — มีลำดับเหตุการณ์ ต้นกลางจบ วางเรื่องทั้งหมดก่อนค่อยหยิบจุดเด่นมาแต่งเป็นท่อนต่าง ๆ

## Song Form — โครงสร้างเพลง

### ส่วนประกอบพื้นฐาน

| ท่อน | หน้าที่ |
|---|---|
| **Intro** | เปิดเพลง สร้างบรรยากาศก่อนเริ่มร้อง |
| **Verse** (ท่อนธรรมดา) | ให้ข้อมูลพื้นฐานของเนื้อหา เล่าเรื่อง พลังงานต่ำกว่า Chorus |
| **Pre-Chorus** | สร้างความคาดหวัง ก่อนเข้าฮุค |
| **Chorus** (ท่อนฮุค) | ประเด็นหลักของเพลง (Central Idea) ซ้ำได้ ติดหู ทุกคนร้องตามได้ พลังงานสูงสุด |
| **Bridge** (ท่อนสะพาน/ท่อนส่ง) | เชื่อมระหว่างท่อน (Verse↔Verse หรือ Verse↔Chorus) เปลี่ยนมุมมอง/อารมณ์ |
| **Outro** | ปิดเพลง |

**กฎเหล็ก:** ท่อนประเภทเดียวกัน (Verse 1 กับ Verse 2) ต้องมีโครงสร้างทำนอง จำนวนคำใกล้เคียงกัน ถ้าต่างกันมากต้องแยกเรียกเป็นคนละแบบ ไม่งั้นคนฟังจะรู้สึกสับสน

### รูปแบบเพลง (Song Form) ที่ใช้บ่อยในเพลงไทย — เสนอให้ user เลือกในเฟส 2

1. **Verse / Chorus / Verse / Chorus** (A / B / ฮุค) — เรียบง่าย ตรงไปตรงมา เหมาะกับเพลงสั้น/ป็อปกระชับ
2. **Verse 1 / Verse 2 / Bridge / Chorus** (A / B / ท่อนส่ง / ฮุค) — **พบมากที่สุดในเพลงไทยทั่วไป** เหมาะเป็น default ถ้า user ไม่มีไอเดียเรื่องโครงสร้าง
3. **Verse / Verse / Bridge / Verse** — Bridge เป็นแค่สะพานไม่ติดหู ต้องปิดด้วย Verse อีกครั้งให้รู้สึกจบ เหมาะกับเพลงที่เน้นเล่าเรื่องมากกว่าฮุคติดหู

บางเพลงมี Bridge สองท่อน (Bridge 1 / Bridge 2) เพื่อเชื่อม Chorus กับ Chorus ท่อนท้าย

### Mapping โครงสร้างเพลงกับ "หน้าที่เชิงเรื่องราว" (ใช้เมื่อ user เลือกแต่งแบบ Plot)
เวลาเพลงเป็นแบบ Plot (มีลำดับเหตุการณ์) การผูกแต่ละท่อนกับ "หน้าที่ในการเล่าเรื่อง" ช่วยให้ไม่หลงทางว่าแต่ละท่อนควรเล่าอะไร:

| ท่อน | หน้าที่เชิงเรื่อง |
|---|---|
| Verse 1 | **Setup** — ปูตัวละคร/บริบท |
| Pre-Chorus | **Conflict** — ก่อความรู้สึกตึงเครียด/คาดหวัง |
| Chorus | **Climax** — จุดพีค ใจความหลักของเพลง |
| Verse 2 | **Development** — พัฒนาเรื่องต่อจาก Verse 1 (มักสั้นกว่า Verse 1 เล็กน้อย) |
| Bridge | **Turning Point** — จุดพลิกอารมณ์/มุมมอง เหมาะเก็บโมเมนต์พิเศษที่ไม่ได้พูดตรง ๆ ในท่อนอื่น |
| Outro | **Resolution** — ปิดจบ ย้ำความรู้สึก/คำสัญญา |

ถ้าเพลงใช้โครงสั้นแบบ Verse/Chorus/Verse/Chorus (ไม่มี Pre-Chorus/Bridge) ให้อนุโลม mapping เหลือแค่ Verse1=Setup, Chorus=Climax, Verse2=Development, Chorus(ซ้ำ)=ย้ำ Climax, Outro=Resolution สั้น ๆ

### กะเวลาเพลงเมื่อจำกัดความยาว (เช่น ไม่เกิน 3 นาที)
โครง 6 ส่วน (Verse1-PreChorus-Chorus-Verse2-Bridge-Chorus-Outro) ใส่ในเพลง ~2:45 ได้สบาย — แบ่งเวลาคร่าว ๆ Verse ~25-30s, Pre-Chorus ~15s, Chorus ~30s, Bridge ~20s, Outro ~15-20s แล้วปรับตามจริง โครง 4 ส่วนแบบสั้น (Verse/Chorus/Verse/Chorus) ยิ่งใส่ในเวลาสั้นได้ง่ายกว่า (~2:30)

## ศัพท์ที่ควรอธิบายให้ user เข้าใจง่าย ๆ เมื่อใช้คำเหล่านี้ครั้งแรก

| ศัพท์ | อธิบายง่าย ๆ ให้ user |
|---|---|
| วรรค | หนึ่งประโยค/ท่อนคำก่อนหยุดหายใจตอนร้อง |
| เสถียร | ฟังแล้วรู้สึก "จบ สมบูรณ์" |
| ไม่เสถียร | ฟังแล้วรู้สึก "ค้างคา ต้องมีต่อ" |
| ฮุค (Hook) | ท่อนที่ติดหู จำง่ายที่สุดของเพลง มักอยู่ใน Chorus |

## โวหารภาพพจน์ — คลังคำ "กวี" ให้เนื้อเพลงไม่จืดชืดเหมือนพูดปกติ

ใช้เมื่อ user (หรือ Claude เอง) รู้สึกว่าเนื้อเพลงที่ร่างมา "ตรงเกินไป" ฟังเหมือนประโยคพูดทั่วไปมากกว่าเนื้อเพลง — สลับมาใช้โวหารเหล่านี้แทนคำตรง ๆ:

| โวหาร | คืออะไร | ตัวอย่าง |
|---|---|---|
| **อุปมา (Simile)** | เปรียบสิ่งหนึ่งเหมือนอีกสิ่ง ใช้คำเชื่อม เหมือน/ดุจ/ดั่ง/ราว/ราวกับ/ปาน/ประหนึ่ง/เพียง | "รอยยิ้มเธองามดั่งดอกไม้บาน" |
| **อุปลักษณ์ (Metaphor)** | เปรียบสิ่งหนึ่ง "เป็น/คือ" อีกสิ่งหนึ่งตรง ๆ โดยไม่ใช้คำเชื่อมเปรียบก็ได้ | "เธอคือแสงดาวกลางคืนมืดมิด" |
| **นามนัย (Metonymy)** | ใช้ส่วนหนึ่งของสิ่งนั้นแทนทั้งหมด | "หัวใจ" แทนความรัก, "สายลม" แทนอิสรภาพ |
| **สัญลักษณ์ (Symbol)** | ใช้สิ่งหนึ่งแทนความหมายที่สังคมเข้าใจร่วมกัน | ดอกไม้ แทน ความสวยงาม/เปราะบาง, ท้องฟ้า แทน อิสระ/ความฝัน |
| **อติพจน์ (Hyperbole)** | กล่าวเกินจริงเพื่อเน้นอารมณ์ | "คิดถึงจนใจจะขาด" |
| **ปฏิพากย์ (Oxymoron)** | เอาคำขัดแย้งกันมารวมกันเพื่อเอฟเฟกต์พิเศษ | "น้ำผึ้งขม", "ยิ่งใกล้ยิ่งไกล" |

**หลักใช้จริง:** ไม่ต้องยัดทุกโวหารในเพลงเดียว เลือก 1-2 แบบที่เข้ากับธีมเพลงพอ — เช่น เพลงทริปเพื่อน อาจใช้อุปมาเทียบ "สายลม" "ท้องฟ้า" กับความรู้สึกอิสระ/ความทรงจำ
