# Melody Matching — แต่งเนื้อร้องให้ตรงเมโลดี้ที่กำหนดไว้แล้วอย่างเคร่งครัด

ใช้ไฟล์นี้เมื่อ **user มีทำนอง/เมโลดี้แต่งไว้ล่วงหน้าแล้ว** (แต่งทำนองก่อน เนื้อร้องทีหลัง) — ต่างจาก `prosody-and-tone.md` หัวข้อ 7 ("ป้องกันข่มขืนเมโลดี้") ซึ่งเป็นแค่ **guideline คร่าว ๆ** สำหรับใช้ตรวจสอบตอนยังไม่มีทำนองตายตัว (แต่งเนื้อร้องไปพลาง ๆ) ไฟล์นี้คือ**โหมดเคร่งครัด**ที่ล็อกทุกพยางค์ให้ตรงกับเสียงที่กำหนดแบบไม่มีข้อยกเว้น เพราะทำนองถูกกำหนดตายตัวไปแล้ว ร้องผิดเสียงไม่ได้จริง ๆ

## Step 1: แปลงเมโลดี้ที่ user ให้มาเป็น target tone sequence

user อาจให้โจทย์เมโลดี้มาได้หลายรูปแบบ ต้องจัดการต่างกัน:

1. **พยางค์เปล่าแทนเสียง** (เช่น "นา นา น้า หน่า") — **ห้ามเดาเองว่าแต่ละพยางค์แทนเสียงวรรณยุกต์อะไร ต้องถาม user ให้ชัดก่อนเสมอ** พยางค์หน้าตาเดียวกันอาจถูกตั้งใจให้แทนเสียงต่างกันได้ (มีเคสจริงที่ user ตั้งใจให้ "น้า" แทนเสียงจัตวาไม่ใช่ตรีตามที่มันออกเสียงจริง) — ยึดตามที่ user ยืนยันเป็นหลัก ไม่ใช่ตามหลักภาษาศาสตร์จริงของพยางค์นั้น
2. **โน้ตดนตรี** (Do Re Mi Fa Sol La Ti) — แปลงเป็นวรรณยุกต์เป้าหมายคร่าว ๆ ได้ตามนี้ (เป็นการเทียบแบบง่าย ไม่ใช่กฎตายตัว ให้ถาม/ยืนยันกับ user เสมอถ้าไม่ชัวร์):
   - โน้ตต่ำสุดในกลุ่ม → เอก
   - โน้ตกลาง → สามัญ
   - โน้ตกลางค่อนสูง/มีการเอื้อนขึ้นปลาย → จัตวา
   - โน้ตสูงสุด → ตรี
   - โน้ตที่เริ่มสูงแล้วมีการเอื้อนลงปลาย → โท
3. **ระบุเสียงวรรณยุกต์เป้าหมายมาตรง ๆ ทีละพยางค์** — ใช้ได้เลยไม่ต้องแปลงอะไรเพิ่ม เป็นวิธีที่แม่นยำที่สุด แนะนำให้ user ทำแบบนี้ถ้าเป็นไปได้

## Step 2: หาคำที่ตรงเสียงเป๊ะทุกพยางค์

**ลำดับความสำคัญในโหมดนี้ (กลับด้านจากโหมดกลอนแปดปกติ): เสียงตรงเป๊ะ > ไม่ซ้ำคำ > ความหมายลื่นไหล** เพราะจุดประสงค์คือร้องแล้วไม่เพี้ยนเสียงเทียบกับทำนองที่ตายตัวแล้ว ไม่ใช่ความไพเราะของประโยค — ต่างจาก `prosody-and-tone.md` หัวข้อ 7 ที่ให้ความหมายมาก่อนเสมอ

ขั้นตอน: ไล่ทีละตำแหน่ง เลือกคำจากคลังคำแยกตามเสียงวรรณยุกต์ (ดูด้านล่าง) ที่ตรงเสียงเป๊ะก่อน แล้วค่อยดูว่าเรียงกันแล้วพอมีความหมายไหม เช็คคำซ้ำทั้งท่อนก่อนส่งเสมอเหมือนโหมดปกติ

## Step 3: ถ้าหาคำที่ทั้งเสียงตรงและความหมายลื่นไม่ได้

**แจ้ง user ตรง ๆ ว่าเจอทางตัน แล้วเสนอ 3 ทางเลือกเสมอ อย่าเดาเลือกเองว่า user อยากได้แบบไหน:**
1. หักท่อนนั้นเป็นช่วงสั้น ๆ ค่อย ๆ หาทีละช่วง
2. ผ่อนกฎบางอย่าง (เช่น ยอมคำซ้ำได้บ้าง) เพื่อความหมายลื่นขึ้น
3. เสียงตรงเป๊ะที่สุดเท่าที่ทำได้ ยอมความหมายหลวม/เป็นภาพพจน์แทนประโยคสมบูรณ์

## คลังคำเริ่มต้นแยกตามเสียงวรรณยุกต์ (ขยายเพิ่มเรื่อย ๆ ทุกครั้งที่เจอคำใหม่ที่ใช้ได้)

| เสียง | คำตัวอย่าง |
|---|---|
| สามัญ | นา, กัน, ทาง, ยัง, มา, ไป, ใจ, งาม, นอน, วัน, เธอ, ลม, ยิ้ม, เย็น, นาน, ไกล, คืน |
| เอก | ต่อ, ป่า, ก่อน, ข่าว, ส่ง, ผ่าน, ห่าง, ขาด, สุด, หมด, จบ, ผิด, จ่าย, ต่าง, เก็บ, จาก |
| โท | แม้, ไม่, มั่น, ค่า, ว่า, น่า, ให้, ทุ่ง |
| ตรี | รัก, นึก, มัด, ลึก, นับ, รับ, น้ำ, ค้าง, ทุก |
| จัตวา | ฝัน, ไกล(ผิด-ที่จริงสามัญ ตัดออก), ขาว, หวาน, ไหน, สวย, เหงา, ฟ้า, หา, ขอ, เสมอ, ไหว |

*(ที่มา: สร้างจากเซสชันจริงที่ user ให้โจทย์เมโลดี้ "นา นา น้า หน่า" มาให้แต่งเนื้อร้องเทียบเสียงเป๊ะทุกพยางค์ — เพิ่มเข้า reference เมื่อ ส.ค. 2026)*
