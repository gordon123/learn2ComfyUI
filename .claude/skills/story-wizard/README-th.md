# story-wizard

*[English](README.md)*

ชั้นเหตุผลเรื่อง story ที่ทำงาน**ก่อน**การวิเคราะห์ฟุตเทจเชิงเทคนิคหรือเขียน prompt ใดๆ
เมื่อผู้ใช้ส่งคลิปอ้างอิง (หรือภาพ character reference) มาพร้อมขอให้สร้าง/ปรับเปลี่ยนใหม่
จากมัน แก้ gap ที่มีอยู่จริง: ทั้ง `reelbench-skills` (วัด shot grammar) และ
`personal-video-library` (เพิ่มเทคนิคกล้องทับของเดิม) ไม่เคยถามเลยว่าชิ้นงานใหม่**เกี่ยวกับ
อะไร** — character ทำอะไร ทำไม เปิดเรื่องยังไง จบยังไง prompt อาจเป๊ะเรื่องภาษากล้องแต่ไม่มี
เหตุผลให้ดูเลยถ้าไม่มีใครตัดสินใจเรื่อง story

## ใช้เมื่อไหร่

- มีคลิปอ้างอิง/ภาพ character ส่งมาพร้อมคำขอให้ปรับ/รีมิกซ์/สร้างใหม่ — ไม่ใช่แค่ทำซ้ำ
  shot-ต่อ-shot
- คำขอเอ่ยถึง character/subject แต่ไม่ได้บอก action, hook หรือตอนจบ
- ก่อนที่ `personal-video-library` จะรัน technical analysis ของ `reelbench-skills` — นี่คือ
  Phase 0 อยู่เหนือทั้งสองตัว

ไม่ใช้กับ shot สินค้านิ่งๆ ช็อตเดียว, การสาธิตเทคนิคล้วนๆ, หรือคำขอที่ระบุ action/hook/
ตอนจบมาครบแล้ว (แค่ยืนยันความเข้าใจสั้นๆ แล้วไปต่อ)

## Workflow (ดู `SKILL.md` สำหรับรายละเอียดเต็ม)

1. **อ่านคลิปอ้างอิง** — อ่านแบบบรรยายตรงๆ ว่าในคลิปมีใคร/อะไร ทำอะไร บรรยากาศ/mood เป็นยังไง
   — ไม่ใช่การวัด shot grammar เชิงเทคนิค
2. **ถามแบบ Socratic** — ถามผู้ใช้ตรงๆ ว่าครั้งนี้อยากให้ character ทำอะไร นำเสนอยังไง มี
   story telling ยังไง hook อะไร ตอนจบจบแบบไหน
3. **สร้าง Story Brief** — รวมคำตอบเป็น brief สั้นๆ มีโครงสร้าง แล้วให้ผู้ใช้ยืนยันก่อนไปต่อ
4. **ส่งต่อ** — เอา brief นี้ไปให้ `personal-video-library`/`reelbench-skills` ใช้เป็นบริบท
   narrative ที่งาน technical/rhythm ของพวกมันจะสร้างทับ

## ความสัมพันธ์กับ skill อื่น

| Skill | ตอบคำถามว่า |
|---|---|
| `story-wizard` (ตัวนี้) | ชิ้นงานใหม่เกี่ยวกับอะไร — action, hook, arc, ตอนจบ? |
| `reelbench-skills` | ฟุตเทจอ้างอิงวัดออกมาเป็นอะไรบ้าง แต่ละ shot? |
| `melies-cinematic-library` | เทคนิคกล้อง/แสง/เอฟเฟกต์นี้มีชื่อเรียกที่ถูกต้องว่าอะไร? |
| `personal-video-library` | ฉันเคยเก็บอะไรไว้บ้าง แล้วจะเพิ่มเติมแทนที่จะก็อปได้ยังไง? |
| `mv-storytelling-framework` | กลไกถามแบบเดียวกัน แต่ล็อกกับเพลง/เนื้อเพลง — ใช้ตัวนั้นแทนถ้า source เป็นเพลง ไม่ใช่คลิป |
